# 00 项目总览

> 状态：文档完成。代码在 Mock 环境验证；**未在真机运行**。证据等级见 `EVIDENCE_MATRIX.md`。

## 一句话

在恩培 Episode 1 六轴机械臂的**官方控制链之上**，做一层可测试的安全控制与轨迹执行系统：加固 TCP/JSON SDK、显式状态机、单一运动所有权仲裁、带时间戳的状态缓存、安全监督与轨迹监视，并给出 ROS2 / ros2_control 接入实现。

## 为什么做

官方链路（B/C 级证据）能“让机械臂动起来”，但从系统工程角度有几个空白：

| 观察（来源） | 风险 |
|---|---|
| 历史服务器单次 `recv(8)` 读长度头（C） | TCP 短读时协议错位 |
| 历史服务器用 `pickle` 反序列化网络数据（C） | 可被远程执行代码 |
| 每个客户端一个线程，命令无锁（C） | 多个调用方的运动命令在一条 CAN 总线上交错（D） |
| 运动命令返回“预计耗时”，客户端 `sleep` 等待（C） | “时间到了”被当成“到位了” |
| 未知命令不回复（C） | 客户端无超时则永久阻塞 |
| 关节读数可能为 `None`（B，论坛 tid=1932） | 不完整数据被当作有效状态 |
| 回零基于堵转电流，J5 皮带打滑会改变零点（B，tid=1953/1996） | 电机侧编码器“看不到”输出侧误差 |

| | 故障注入测试、性能测量工具与技术文档 |
